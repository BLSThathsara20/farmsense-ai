## LinkedIn post (copy this)

Building FarmSense AI taught me more than any single lecture.

A few honest lessons:

**1. Users need trust more than complexity.**  
A clear “why this crop?” matters more than ten hidden scores.

**2. Missing data is a product problem.**  
If a live signal fails, say “unavailable.”  
Do not fake confidence.

**3. Full-stack is the real exam.**  
Model + API + database + UI + Docker.  
Each part can break the story.

**4. Local context matters.**  
A global soil dataset is useful for learning.  
A UK farm still needs filters, price sources, and careful claims.

**5. Overproduction is a community problem.**  
If everyone plants the same crop nearby, “good soil advice” can still hurt incomes.

I am still a student.  
The project is still growing.  
But I am proud that it tries to be useful and honest at the same time.

If you are working on your final-year project:

Start with a real pain.  
Build something people can click.  
And write down what you got wrong.

Thanks to everyone who followed this short series.
