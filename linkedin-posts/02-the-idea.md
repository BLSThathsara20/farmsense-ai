## LinkedIn post (copy this)

In my last post I talked about the problem:

Farmers often decide crops with incomplete information.

So what is FarmSense AI?

It is a simple idea with a serious goal.

Help a farmer see a plan **before** planting:

1. **What crop** fits the soil  
2. **When to sow**  
3. **When selling** may make more sense  

And one more thing many tools miss:

**Is everyone nearby planting the same crop?**

Because if a whole district grows the same thing, prices can crash at harvest time.

FarmSense AI brings a few signals into one place:

- soil suitability  
- weather fit  
- price outlook  
- demand / local oversupply awareness  

I am building it as my final-year Computing project at Northumbria University.

Stack in plain words:

- a web app farmers can open on a phone  
- an API that runs the logic  
- a database that stores farms and plans  
- machine learning models behind the ranking  

It is still a student project.  
It is not magic.  
It will not replace a farmer’s judgment.

But it tries to replace **guesswork with a clearer first answer**.

Next post: how I am building it, and why I chose this tech.

If you have built something for real users before — what mattered more to you: accuracy, or trust?
